Primary Focus

Documentation
Description

This mentorship focuses on improving the usability, maintainability, and contributor experience of Hyperledger Cacti. Following the merger of Hyperledger Cactus and Weaver, the codebase and architecture have grown complex, with fragmented documentation and legacy components that hinder onboarding and long-term sustainability.

The project targets the ongoing Cacti Cleanup Initiative, aiming to simplify architecture, remove deprecated modules, improve security, and create high-quality documentation. The mentee will audit and restructure developer and user documentation, align docs with the evolving architecture, identify outdated components for removal, and improve onboarding guides and contribution workflows.

Implementation will follow an iterative process: reviewing GitHub issues and cleanup boards, proposing improvements, implementing updates to documentation and selected code areas, and validating improvements with maintainers. The outcome will be a streamlined, well-documented Cacti framework that lowers entry barriers for contributors and strengthens the project’s long-term sustainability.
Learning Objectives

    Understand cross-chain architectures and pluggable DLT frameworks
    Gain experience contributing to a large open-source project under the LF Decentralized Trust ecosystem
    Learn best practices for technical documentation, developer experience, and onboarding design
    Develop skills in codebase refactoring, modularization, and security-driven cleanup
    Collaborate with an international open-source community using GitHub, CI/CD pipelines, and review workflows

Expected Outcome and Deliverables

    A restructured and standardized documentation suite (developer, user, and architecture docs)
    Cleanup contributions removing deprecated or low-value components and simplifying modules
    Improved onboarding guides, tutorials, and contributor documentation
    CI/CD improvements reducing pipeline runtime and complexity (where applicable)
      - CI/CD audit completed and documented in `researches/cacti_cicd_final_audit.md`
    A final report summarizing changes, impact, and recommendations for future improvements

Relation to LF Decentralized Trust and impact on the community

This mentorship directly contributes to Hyperledger Cacti, the major interoperability project within LF Decentralized Trust. By improving documentation, simplifying architecture, and enhancing onboarding, the project strengthens the usability and adoption of interoperability technologies across networks such as Hyperledger Fabric, Besu, and other DLT platforms.

The impact includes lowering barriers to entry for developers and researchers, improving security posture through reduced complexity, and enabling broader experimentation and innovation in cross-chain applications. These improvements help accelerate the adoption of interoperable blockchain systems in both academic and enterprise ecosystems.
